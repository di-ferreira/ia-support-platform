# EMSoft Support AI — Ponteiro (resumo histórico)

> **RESUMO HISTÓRICO.** Este arquivo registrou a visão inicial completa do projeto.
> A fonte de verdade é `docs/specs/`; este arquivo é apenas um resumo histórico.

## Visão

Plataforma SaaS de suporte técnico do ERP EMSoft por WhatsApp: atendimento por IA com
base de conhecimento RAG, kanban operacional e escala para atendente humano.

## Stack real

- Backend: FastAPI (Python) + Appwrite + Redis + Qdrant
- Transporte: Evolution API + n8n
- Frontend: Next.js 15

> Detalhes de arquitetura, contrato de API, RBAC e pipeline de IA em `docs/specs/`.
